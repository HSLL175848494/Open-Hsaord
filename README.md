# Open-Hsaord

接入自己的信号服务器，在手机 Binance 事件合约页面自动下单。下单通过无障碍服务操作，行情、订单记录、盈亏统计和运行日志都能在应用里查看。

当前版本 **v1.0.0**，支持 **Android 10 及以上**。这里只提供应用安装包和 API 文档，信号服务器需要自己准备。

## 功能

| 功能 | 说明 |
| --- | --- |
| 连接服务器 | 填写域名或 IP、端口和 Token，支持 HTTP、HTTPS，可导入服务器证书 |
| 行情预测 | 查看服务器返回的价格、方向、置信度和周期，支持 BTCUSDT、ETHUSDT |
| 自动下单 | 按服务器推单下单，执行前检查账户、页面和交易条件，跳过过期或重复订单 |
| 合约周期 | 支持 10 分钟、30 分钟、1 小时、1 天，按推单选择币种和周期 |
| 下单设置 | 设置下单金额、推单有效期和查询频率 |
| 交易限额 | 设置统计窗口内的订单数、累计金额、亏损和盈利上限，达到条件后停止下新单 |
| 订单记录 | 分别查看服务器订单和本地执行记录，按日期、状态筛选，统计盈亏和胜率 |
| 运行状态 | 悬浮球显示运行状态，日志记录请求、下单过程和异常原因 |

行情面板只展示预测，方向或置信度变化不会直接触发下单。自动下单读取服务器单独发布的待验证订单。服务器记录与本地实际成交分别保存，服务器策略统计不代表账户实际收益。

## 使用前准备

- Android 10 或更新版本的手机，已安装并登录 Binance，账户可使用事件合约。
- 符合 API 文档的信号服务器和有效 Token。
- Binance UID 和只读 API Key / Secret，用于核对账户、查询余额和收入流水。
- 为 Open-Hsaord 开启无障碍服务、悬浮窗权限和电池优化豁免。

## 使用步骤

安装 APK 后：

1. 在设置中填写服务器域名或 IP、端口，并选择是否使用 HTTPS。地址只填域名或 IP，不加协议和路径。
2. 填写 Binance UID、服务器 Token 和 Binance 只读 API。Token 绑定的账号、填写的 UID 和 API 所属账号需要一致。
3. 设置下单金额、推单有效期、查询频率和交易限额。推单有效期默认 15 秒，可在应用内调整。
4. 确认无障碍服务、悬浮窗权限和电池优化豁免已开启，再打开自动下单。切换到 Binance 事件合约页面，保持金额、周期和方向按钮可见。
5. 通过悬浮球查看状态，在本地订单中查看执行记录，在服务器订单页查看方向验证结果。遇到问题可查看日志。

应用进程重启后，自动下单会关闭，需要手动重新开启。

## 服务器接入

服务器需要实现服务器信息、Token 状态、实时预测、推单和订单历史查询接口，具体见 [API 文档](https://github.com/HSLL175848494/Event_Api)。
