# Open-Hsaord

**接入自定义信号服务器，在 Android 手机上执行 Binance 事件合约订单。**

Open-Hsaord 将你的策略服务器与手机上的 Binance 事件合约页面连接起来：服务器发布预测与订单，客户端展示行情、检查执行条件，并通过无障碍服务完成页面下单，提供订单记录、收益统计和运行日志，便于查看执行情况。

当前版本 **v1.0.0**，支持 **Android 10 及以上**。本项目提供应用安装包和 API 接入文档，信号服务器需自行准备。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 自定义服务器 | 自行填写服务器域名或 IP、端口和 Token，支持 HTTP、HTTPS，以及导入自定义服务器证书 |
| 实时行情与预测 | 展示服务器提供的价格、预测方向、置信度和周期，支持 BTCUSDT、ETHUSDT |
| 自动执行订单 | 获取有效期内的待验证订单，检查账户、页面和交易条件后执行，并对重复订单去重 |
| 多种事件周期 | 支持 10 分钟、30 分钟、1 小时、1 天，按服务器订单选择对应标的与周期 |
| 交易参数与限额 | 可配置下单金额、订单有效期、查询频率，以及统计窗口内的笔数、金额、亏损和盈利上限 |
| 订单与统计 | 分别查看服务器订单和本地执行记录，支持日期范围、状态筛选及盈亏、胜率统计 |
| 状态与日志 | 通过悬浮球查看运行状态，通过日志追踪请求、执行过程和异常 |

行情面板的预测用于展示，预测方向或置信度变化不会直接触发下单。自动下单读取服务器独立发布的待验证订单；服务器的方向验证记录与本地实际成交分别保存，服务器策略统计也不等同于账户实际收益。

## 使用前准备

- 一台运行 Android 10 或更新版本的手机，已安装并登录 Binance，且账户可以使用事件合约功能。
- 一个按接口文档实现的信号服务器，以及有效的服务器 Token。
- Binance 账户 UID 和只读 API Key / Secret，用于核对账户身份、查询余额与收入流水。下单通过手机页面操作完成。
- 为 Open-Hsaord 开启无障碍服务、悬浮窗权限和电池优化豁免，并按应用提示完成运行条件检查。

## 快速开始

下载并安装发布的 APK 后，按以下步骤完成配置：

1. **配置服务器**：在设置中填写域名或 IP、端口，并根据服务器配置选择 HTTPS；地址栏只填写主机地址，不包含协议和路径。
2. **完成账户认证**：填写 Binance UID、服务器 Token 和 Binance 只读 API。Token 绑定的账户、填写的 UID 与 API 所属账户需要一致。
3. **设置执行参数**：配置下单金额、订单有效期、查询频率和交易限额。
4. **开启自动下单**：确认无障碍服务、悬浮窗权限和电池优化豁免已开启，启用自动下单后切换到 Binance 事件合约页面，保持金额、周期和方向按钮可见。
5. **查看执行结果**：通过悬浮球观察状态，在本地订单和日志中查看执行记录；服务器订单页可查看信号来源的历史验证结果。

应用进程重启后，自动下单默认关闭，需要手动重新开启。

## 服务器接入

服务器需按照 [Event_Api 接口文档](https://github.com/HSLL175848494/Event_Api) 实现对应 API，客户端通过配置的地址定期查询。

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/server` | 查询服务器名称与版本 |
| `GET /api/v1/token` | 校验 Token，查询绑定账户和有效状态 |
| `GET /api/v1/predict` | 获取行情价格与实时预测，用于页面展示 |
| `GET /api/v1/push-orders` | 获取有效期内的待验证订单，用于自动下单 |
| `GET /api/v1/orders` | 分页查询服务器历史订单与方向验证结果 |

订单有效期默认 15 秒，可在应用内调整。请求参数、认证方式、返回格式及订单执行规则请查看 [API 文档](https://github.com/HSLL175848494/Event_Api)。
